# Tontoo CoreText

Apple CoreText-like crisp text stack for TontooOS: font management, layout, crisp rendering, caret mapping.

Wiki: [wiki/MAIN.md](wiki/MAIN.md)

## Made for TontooOS

Explore more at https://github.com/TontooOS/Libs

## Adding to Your Project

Add to your `Cargo.toml`:

```toml
[dependencies]
sdk = { path = "/Library/System/sdk", features = ["CoreText"] }
```
